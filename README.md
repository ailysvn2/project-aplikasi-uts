## Deskripsi Aplikasi
[StudyScore adalah aplikasi sederhana untuk menghitung nilai akhir siswa berdasarkan 4 nilai tugas, UTS, dan UAS.Fungsi Utama nya yaitu menghitung nilai akhir dan membandingkannya dengan target nilai yang diinginkan.Kegunaan nya adalah untuk mempermudah siswa menghitung nilai akhir tanpa harus menghitung secara manual.Fitur aplikasi nya ada
input nama siswa,input 4 nilai tugas,input nilai UTS dan UAS,menghitung rata-rata tugas,menghitung nilai akhir berdasarkan bobot, input target nilai sendiri,menghitung selisih nilai dengan target,menampilkan status target tercapai atau belum.]
